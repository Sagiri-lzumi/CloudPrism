# 百度网盘凭证申请教程

> 本教程指导你在百度网盘开放平台申请应用凭证，并在 CloudPrism 中完成接入。
> 结论先行：**百度网盘 API 非公开，必须申请开发者权限后才能调用**；凭证由你本人申请、本人填写，程序不会内置任何凭证。

---

## 1. 前提与风险

1. 需要一个**百度账号**（建议直接用你自己的网盘账号，它将作为网盘数据的归属账号）。
2. 需要完成**百度个人实名认证**（身份证号 + 真实姓名），这是开放平台的硬性前提。
3. **个人创建应用可能处于暂停状态**。官方曾公告"由于开放平台优化升级，暂停个人创建应用"。若个人通道关闭：
   - 等待个人通道恢复（关注官网公告）；或
   - 进行**企业认证**（需企业资质，审核约 1~3 个工作日）。
4. 申请到的应用默认包含"网盘基础服务能力"（文件读写/上传下载），这正是 CloudPrism 需要的，无需额外开通。

---

## 2. 申请步骤

### 2.1 登录开放平台

- 入口：<https://pan.baidu.com/union/console/home>
- 用百度账号登录（支持百度 APP 扫码）。

### 2.2 申请接入 / 开发者认证

1. 首页右上角点击「**立即申请**」；
2. 阅读并同意《百度网盘开放平台开发者服务协议》；
3. 若未实名认证，按引导填写**真实姓名 + 身份证号**；
4. 绑定手机号与密保邮箱后提交。认证类型：
   - **个人认证**：身份证实名即可；
   - **企业认证**：需企业资质，1~3 个工作日审核。

### 2.3 创建应用

1. 认证通过后进入「**控制台**」→ 点击「**+ 创建应用**」；
2. 应用类型选择「**软件应用**」；
3. 应用名称建议填 `CloudPrism`，描述可写"端到端加密云盘客户端，读写用户网盘文件"；
4. 创建成功后，在应用详情页可以看到四组凭证。

### 2.4 回调地址

- 应用设置中的「授权回调地址（redirect_uri）」**留空即可**；
- CloudPrism 使用 oob 模式：授权后页面直接显示 code，手动粘贴回程序，无需回调地址。

---

## 3. 四组凭证说明

在应用详情页找到以下四项：

| 凭证 | 说明 | 保密级别 |
| --- | --- | --- |
| **Appid** | 应用唯一标识（数字） | 可公开 |
| **AppKey**（client_id） | OAuth 客户端标识 | 保密 |
| **SecretKey**（client_secret） | 换取 token 的密钥 | **严格保密** |
| **SignKey** | 部分接口签名校验用 | 保密 |

> 安全提醒：这些凭证等同于应用的"密码"，请勿发到公开仓库或公开频道。
> CloudPrism 将其经 DPAPI 加密后仅保存在你本机（`%APPDATA%/CloudPrism/baidu.json`），不会上传。

---

## 4. 在 CloudPrism 中填写

1. 打开 **设置 → 百度网盘**，依次填入 Appid / AppKey / SecretKey / SignKey；
2. 点击「**检查**」：校验格式与网络连通性（凭证的最终有效性由登录授权时百度服务器验证）；
3. 点击「**登录百度账号…**」：程序自动打开浏览器授权页；
4. 在浏览器登录百度账号并点「授权」，页面显示一串 **code**；
5. 把 code 粘贴回程序，点「完成授权」；
6. 程序自动换取 `access_token`（30 天）与 `refresh_token`（长效，到期自动续期），完成后即可在初始化向导中选择「百度网盘」后端使用。

---

## 5. 常见错误码速查

| errno | 含义 | 处理 |
| --- | --- | --- |
| 111 | access_token 过期 | 程序自动用 refresh_token 刷新后重试 |
| -6 / -7 | 身份验证失败 | 检查 AppKey / SecretKey 是否填错 |
| 31064 | 授权/权限校验失败 | 检查应用是否审核通过、应用是否具备网盘服务 |
