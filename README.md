# CloudPrism

[![License](https://img.shields.io/badge/License-AGPL--3.0-green.svg)](LICENSE)

端到端加密的云盘客户端。文件在本地完成加解密，云端只保存密文。

CloudPrism 是一个 Windows 单文件程序：双击运行后常驻系统托盘，并自动用系统
默认浏览器打开界面。不需要安装，不写注册表，所有数据都放在程序旁的 `data/`
目录里，拷走即走。

## 功能

### 文件管理

- **上传与下载**：文件在本地加密后上传，下载后在本地解密；上传即占位、
  完成即刷新，全程有进度反馈
- **文件夹上传**：递归展开，在密库中保留原来的目录结构
- **拖放上传**：文件或文件夹拖到界面任意位置即入队
- **网格与列表两种视图**：一键切换，适合浏览大量文件或按详情排序
- **多选与批量操作**：选中多项后可批量下载、导出、删除
- **右键菜单**：打开、下载、重命名、删除、导出到指定目录

### 预览与播放

- **图片预览**：即点即显，缩略图服务端重编码后缓存
- **文本预览**：txt、Markdown 等直接内嵌阅读
- **视频播放**：边解密边播放，拖动进度条可立即跳到任意位置（不必等整文件下完）；
  视频卡片自动抽取中心帧作为封面，并标注时长
- **PDF 直读**：PDF 在浏览器内置阅读器中直接打开，支持缩放、翻页、搜索与打印
- **音频播放**：流式解密播放
- 格式不支持的文件提供「用系统默认程序打开」

### 界面体验

- **毛玻璃质感**：侧栏、页头、底栏、菜单、对话框均为磨砂玻璃；页面内容滚动时
  会从顶部玻璃页头底下穿过，层次分明
- **弹性动效**：按钮、卡片、列表行的悬停与按压带轻微回弹；切换页面、切换视图、
  新条目出现都有过渡动画
- **明暗主题**：跟随系统或手动切换浅色 / 深色
- **响应式布局**：窄窗口下侧栏收为图标条，手机宽度下改为底部标签栏

### 存储后端

- **本地文件夹**：任意本地目录作为密库存储
- **WebDAV**：支持标准 WebDAV 服务器
- **百度网盘**：需在百度开放平台申请应用凭证（见随包 `baidu_guide.md`）

### 安全

- **主密码**：经 PBKDF2 加随机盐派生密钥，密钥仅驻留内存，退出即清除；
  主密码不落盘，忘记后只能凭恢复码找回
- **文件加密**：AES-CTR 流式加密，支持从任意位置开始解密（所以视频能随意拖动）
- **文件名加密**：建库时可开启，开启后远端的目录与文件名全部是密文，结构不可见
- **密库完整性**：密库元信息用 AES-GCM 认证加密，被篡改可被发现
- **暂存回收**：上传暂存的明文在任务结束后回收
- **局域网令牌**：开启局域网访问后，同一网络内的设备需凭访问令牌打开界面；
  本机访问免令牌；取不到令牌时自动回退为仅本机监听
- **日志脱敏**：不记录密码与密钥

### 便捷特性

- **快速重连**：记录最近使用的密库，重连只需输入一次主密码
- **恢复码**：建库后可在设置页生成恢复码，用于主密码遗忘时找回访问（务必妥善保存，
  否则密库中的数据无法恢复）
- **自动锁定**：可设置空闲一段时间后自动锁库
- **局域网访问**：开启后同一网络内的设备可打开界面操作同一个密库
- **便携存储**：设置与数据保存在程序目录旁的 `data/`，不写注册表与用户目录
- **快捷键**：F5 刷新、Ctrl+U 上传、Ctrl+D 下载、Ctrl+L 锁库

## 使用

运行 `CloudPrismGo.exe` 即可。程序常驻系统托盘，并自动打开浏览器指向本地服务
（默认端口 7840，被占用时顺延）。发布包按 `Release/<日期>-<版本>-Go-dir/` 与
`...-Go-exe/` 两种形态产出：目录版含 exe、随包资源与使用说明，单文件版只有 exe。

首次运行进入初始化向导：选择存储位置 → 测试连接 → 设置主密码 → 选择是否
加密文件名。其中两项在建库后不可更改：

- 主密码不落盘。忘记后只能凭恢复码找回访问，恢复码需事先在设置页生成，
  否则密库中的数据无法恢复。
- 文件名加密在建库时确定，之后无法修改。

## 从源码构建

需要 Go ≥ 1.25。前端产物已入库，纯 Go 构建不需要 Node。

```powershell
cd WindowsGo
$env:CGO_ENABLED = "0"
go build -ldflags "-s -w -H windowsgui" -o build\bin\CloudPrismGo.exe .
```

改动前端源码时先用 Node ≥ 20 重建产物：

```powershell
npm --prefix frontend run build
```

发布打包用 `WindowsGo/build/release.ps1`，产出 `Release/` 下的便携目录版与
单文件版。

## 已知限制

- exe 没有图标与版本元数据（纯 `go build` 不生成资源段）
- 「检查更新」引擎已实现，界面暂无入口
- 传输速度与缓存占用指标当前不上屏
