# CloudPrism

[![License](https://img.shields.io/badge/License-AGPL--3.0-green.svg)](LICENSE)
[![Platform](https://img.shields.io/badge/Platform-Windows-blue.svg)](https://golang.org)
[![Go](https://img.shields.io/badge/Go-%3E%3D1.25-00ADD8.svg)](https://golang.org)

> 端到端加密的云盘客户端 —— 文件在本地完成加解密，云端只保存密文。

CloudPrism 是一个 Windows 桌面应用：双击运行后常驻系统托盘，并自动在系统默认
浏览器中打开操作界面。无需安装，不写注册表，所有配置与数据都存放在程序旁的
`data/` 目录中，可随程序整体携带。

## 特性

### 文件管理

- **端到端加密的上传/下载** —— 文件在本地加密后上传，下载后在本地解密
- **文件夹上传** —— 递归展开并保留原有目录结构
- **拖放上传** —— 文件或文件夹拖入界面任意位置即可入队
- **网格 / 列表双视图** —— 一键切换，适配浏览与排序
- **多选批量操作** —— 批量下载、导出、删除
- **右键上下文菜单** —— 打开、下载、重命名、删除、导出到指定目录

### 预览与播放

- **图片预览** —— 即点即显，缩略图由服务端重编码并缓存
- **文本预览** —— txt / Markdown 等直接内嵌阅读
- **视频播放** —— 边解密边播放，进度条可即时跳转任意位置；视频卡片自动抽取
  中心帧作为封面并标注时长
- **PDF 内嵌阅读** —— 浏览器内置阅读器中直接打开，支持缩放、翻页、搜索与打印
- **音频播放** —— 流式解密播放
- 不支持的格式提供「用系统默认程序打开」兜底

### 界面

- **毛玻璃质感** —— 侧栏、页头、底栏、菜单、对话框均为磨砂玻璃；页面内容
  滚动时从顶部玻璃页头下方穿过，层次分明
- **弹性动效** —— 按钮、卡片、列表行的悬停与按压带轻微回弹；页面切换、
  视图切换、新条目出现均有过渡动画
- **明暗主题** —— 跟随系统或手动切换
- **响应式布局** —— 窄窗口下侧栏收为图标条，手机宽度下改为底部标签栏

### 存储

- **本地文件夹** —— 任意本地目录作为密库存储
- **WebDAV** —— 标准协议支持
- **百度网盘** —— 需在百度开放平台申请应用凭证（见随包 `baidu_guide.md`）

### 安全

- **主密码** —— 经 PBKDF2 加随机盐派生密钥，密钥仅驻留内存，退出即清除；
  主密码不落盘
- **文件加密** —— AES-CTR 流式加密，支持从任意位置开始解密
- **文件名加密** —— 建库时可开启，开启后远端目录与文件名全部为密文，结构不可见
- **密库完整性** —— 元信息用 AES-GCM 认证加密，篡改可被发现
- **暂存回收** —— 上传暂存的明文在任务结束后回收
- **局域网令牌** —— 开启局域网访问时，同网设备需凭访问令牌打开界面；本机访问
  免令牌；取不到令牌时自动回退为仅本机监听
- **日志脱敏** —— 不记录密码与密钥

### 便捷

- **快速重连** —— 记录最近使用的密库，重连只需输入一次主密码
- **恢复码** —— 建库后可在设置页生成，用于主密码遗忘时找回访问
- **自动锁定** —— 可设置空闲一段时间后自动锁库
- **局域网访问** —— 开启后同网设备可操作同一密库
- **便携存储** —— 数据保存在程序目录旁的 `data/`，不写注册表与用户目录
- **快捷键** —— F5 刷新 · Ctrl+U 上传 · Ctrl+D 下载 · Ctrl+L 锁库

## 快速开始

1. 下载发布包（`Release/<日期>-<版本>-Go-dir/` 目录版或 `-Go-exe/` 单文件版）。
2. 运行 `CloudPrismGo.exe`，程序常驻托盘并自动打开浏览器界面。
3. 首次运行进入初始化向导：选择存储位置 → 测试连接 → 设置主密码 →
   选择是否加密文件名。

> 主密码不落盘，**忘记后只能凭恢复码找回访问**。恢复码需在设置页事先生成，
> 否则密库中的数据无法恢复。文件名加密在建库时确定，之后无法修改。

默认本地服务端口为 `7840`，被占用时自动顺延。

## 从源码构建

需要 Go ≥ 1.25。前端产物已入库，纯 Go 构建不需要 Node。

```powershell
cd WindowsGo
$env:CGO_ENABLED = "0"
go build -ldflags "-s -w -H windowsgui" -o build\bin\CloudPrismGo.exe .
```

改动前端源码时需先用 Node ≥ 20 重建产物：

```powershell
npm --prefix frontend run build
```

发布打包用 `WindowsGo/build/release.ps1`，产出 `Release/` 下的便携目录版与
单文件版。

## 项目结构

```
CloudPrism/
├── WindowsGo/            # Windows 客户端（纯 Go 单 exe）
│   ├── frontend/         # Vue 3 + Vite + TypeScript 界面
│   ├── build/            # 打包脚本
│   ├── internal/         # 后端业务逻辑
│   ├── pkg/              # 可复用包（协议、流式传输等）
│   └── docs/            # 工程文档
├── Release/              # 发布产物（打包生成）
├── LICENSE
└── README.md
```
